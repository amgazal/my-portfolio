# Deployment

The portfolio is served by GitHub Pages at https://amgazal.com/.

This is a static HTML/CSS/JavaScript site with no build step. Preserve `CNAME`
and include the referenced images, favicon, and `Abdallah_Gazal_Resume.pdf`
when publishing an approved revision.

`QA.md` is local development documentation, excluded from version control.
If packaging files manually, exclude it from the published files as well.
