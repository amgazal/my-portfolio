Layer

Layer turns a weather forecast into a clothing recommendation calibrated to the person using it.

I started it after moving from Kumasi to Ithaca and realizing that a forecast could be accurate without being useful to me. I designed the React interface and the system behind it: PostgreSQL and Supabase, local first sync, authentication, feedback, and automated tests.

  • Designed a PostgreSQL schema and Row Level Security rules for profiles, calibration state, and feedback.
  • Built local first behavior with queued writes and idempotency protection so a weak connection does not break the experience.
  • Kept the personalization logic separate from the UI and covered it with 40 unit tests.
  • Added GitHub Actions checks so tests, regression checks, and builds run before deployment.

AI4ALL · Team project 2026

AI Tweet Detection

An AI4ALL team project that classifies tweets as human written or AI generated and exposes the result in Streamlit.

We combined TweepFake and ElectAI, cleaned the data into one training pipeline, and compared BERT with classical baselines so we could look at confidence and model agreement, not just a single label.

  • Cleaned and standardized 35K+ tweets from TweepFake and ElectAI while keeping source and generator labels traceable.
  • Compared BERT, Random Forest, and Logistic Regression for human versus AI classification.
  • Built a Streamlit experience that shows prediction, confidence, AI probability, and model agreement.
