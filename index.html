Shipped · public pilot · 2026

Layer — a weather app that learns how cold you feel

Forecasts tell you the temperature. They do not tell you what to wear, and 68° means something different to someone who grew up in Kumasi than to someone who grew up in Ithaca. Layer learns the difference from your feedback.

I built the whole thing: the React interface, the PostgreSQL schema, the security model, the sync protocol, and the deploy pipeline. It runs local-first, so it works with no account and never blocks rendering on the network. Signing in turns on cloud sync and makes your calibration recoverable on another device.

  • Designed a PostgreSQL schema (profiles, calibration state, an append-only feedback log) secured with Row-Level Security, check constraints, and triggers, so the server — not the browser — decides who owns a row and when it was written
  • Built offline-first sync with an outbox queue and client-generated idempotency keys, so retrying after a dropped connection never duplicates a record
  • Kept the calibration model in a pure module with no UI code so it could be tested in isolation; 40 unit tests cover it
  • Wired GitHub Actions to run regression checks, tests, and the build before every deploy
