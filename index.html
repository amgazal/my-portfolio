Layer

Layer started from a problem I kept running into after moving to Ithaca: the forecast told me the temperature, but not what that temperature meant for me.

I turned that idea into a full-stack weather app that recommends what to wear, adjusts for the outing, and learns from feedback. I built the React interface, PostgreSQL data model, sync behavior, authentication flow, and deployment pipeline.

  • Designed a PostgreSQL schema and Row-Level Security rules for profiles, calibration state, and feedback.
  • Built local-first behavior with queued writes and idempotency protection so a weak connection does not break the experience.
  • Kept the personalization logic separate from the UI and covered it with 40 unit tests.
  • Added GitHub Actions checks so tests, regression checks, and builds run before deployment.

AI4ALL · Team project 2026

AI Tweet Detection

My AI4ALL team built a classifier to tell whether a tweet was written by a person or generated by AI, then put the models behind a Streamlit interface.

We merged two research datasets instead of depending on one source and compared different model families so the app could show more than a single prediction.

  • Cleaned and standardized 35K+ tweets from TweepFake and ElectAI while keeping source and generator labels traceable.
  • Compared BERT, Random Forest, and Logistic Regression for human-vs-AI classification.
  • Built a Streamlit experience that shows prediction, confidence, AI probability, and model agreement.
